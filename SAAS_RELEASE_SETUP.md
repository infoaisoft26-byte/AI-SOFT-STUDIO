# SaaS production release checklist

## Required Vercel environment variables

Set these in Preview first, test, then Production:

- DATABASE_URL — existing Neon connection string.
- ADMIN_SESSION_SECRET — existing session secret, at least 32 characters.
- CRON_SECRET — random secret, at least 32 characters; protects the campaign worker.
- RAZORPAY_KEY_ID — Razorpay API key ID (use Test Mode first).
- RAZORPAY_KEY_SECRET — Razorpay API secret; server-side only.
- RAZORPAY_WEBHOOK_SECRET — webhook signing secret; server-side only.
- META_APP_ID — Meta app ID.
- META_WHATSAPP_CONFIG_ID — WhatsApp Embedded Signup configuration ID.
- META_APP_SECRET — Meta app secret; server-side only.
- META_TOKEN_ENCRYPTION_KEY — random secret at least 32 characters; encrypts tenant tokens.
- WHATSAPP_VERIFY_TOKEN — webhook verification token.
- WHATSAPP_GRAPH_API_VERSION — v26.0 unless Meta requires a newer supported version.

Never put secrets in Git, browser code, screenshots or chat messages. Add them in Vercel Project Settings → Environment Variables. Redeploy after changing values.

## Razorpay setup

1. Create or use the AI SOFT STUDIO Razorpay merchant account.
2. Enable Test Mode and generate a Key ID and Key Secret.
3. Add the three Razorpay variables above to Vercel Preview.
4. Configure webhook URL: https://ai-soft-studio.vercel.app/api/payments/razorpay/webhook
5. Subscribe to the `payment.captured` event and use the same webhook secret in Vercel.
6. Test order creation, successful captured payment, failed payment, invalid signature and duplicate webhook delivery.
7. Only after test-mode sign-off, create Live Mode keys and repeat the setup in Production.

The app activates a plan only after server-side signature verification and a captured payment check. This implementation is a prepaid monthly/yearly plan purchase, not an automatically recurring mandate/subscription.

## Meta WhatsApp setup and Coexistence

1. Use the AI SOFT STUDIO Meta app and correct Business Portfolio.
2. Complete Meta Business Verification and Tech Provider onboarding/Access Verification required for customer Embedded Signup.
3. Create a Facebook Login for Business configuration for WhatsApp Embedded Signup v4 and set the configuration ID in Vercel.
4. Request App Review and Advanced Access for required WhatsApp and business permissions. Put the app Live only when Meta approves.
5. Add `ai-soft-studio.vercel.app` as an allowed JavaScript SDK domain and configure HTTPS OAuth redirect/security settings as required by Meta.
6. Add webhook callback URL https://ai-soft-studio.vercel.app/api/whatsapp/webhook and the same WHATSAPP_VERIFY_TOKEN. Subscribe to the WhatsApp Business Account messages field. Coexistence may also require account_update, history, smb_app_state_sync and smb_message_echoes fields; enable the fields Meta exposes for the app.
7. Ensure the app secret is set. Meta webhook signatures are validated with META_APP_SECRET.
8. Test with a WhatsApp Business app number and a separate Cloud API test number before real customers.

The customer connect button launches the WhatsApp Business app onboarding/Coexistence Embedded Signup option. Eligible customers must have the WhatsApp Business app installed and meet Meta's current eligibility checks. The QR/verification screen is shown by Meta, not generated by this website. Meta controls eligibility and approval; the application cannot bypass them.

## Campaign rules

- Campaign recipients must have a recorded explicit WhatsApp opt-in.
- Campaigns use approved Meta message templates and the selected approved language.
- Provide the approved template's component JSON when the template has variables.
- Meta's 24-hour customer service window and WhatsApp messaging policies still apply.
- Delivery/read/failure receipts update campaign reports from Meta webhooks.
- The queue worker processes small batches and is protected by CRON_SECRET.

## Hosting plan requirement

This is a commercial, paid SaaS product. Vercel documents that Hobby is for non-commercial personal projects and limits Cron Jobs to once per day. The team currently linked to this repository is on Hobby. Upgrade the Vercel team to Pro before deploying the production payment flow and the every-minute campaign worker. After upgrade, keep the campaign cron schedule at every minute; a daily schedule is not suitable for timely campaign processing.

## Live test checklist

- Create a new customer account and verify the 24-hour trial.
- Confirm team/contact/campaign limits at and over their configured thresholds.
- Connect a Meta test business and a coexistence-eligible WhatsApp Business app number.
- Verify inbound, outbound, template, delivered, read and failed webhook events.
- Create a campaign with a small opted-in test audience; verify no non-opted-in contacts receive it.
- Make a Razorpay Test Mode payment; verify only captured payment activates the plan.
- Replay the same payment webhook; confirm the expiry date does not extend twice.
- Test failed payment, bad signature, duplicate payment ID and cross-tenant access.
- Run end-to-end tests in Preview before enabling Production.
